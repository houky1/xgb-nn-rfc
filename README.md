## Файл посвящен анализу данных коллайдера.
В нем строится модель, которая будет предсказывать, является ли событие сигналом (частицей Хиггса) или фоном (другими процессами).
Для этого применена техника блендинга (предсказание модели строится на основе нескольких классификаторов). В качестве классификаторов применялись XGboost, RandomForest, многослойный персептрон на nn.Module.
## Оценка модели
Для оценивания модели на соревновании присутствует специальная метрика AMS. Результат модели составил ~ 1.55.
Проект выполнялся в качестве учебных целей, и требует большого количества дороботок.
