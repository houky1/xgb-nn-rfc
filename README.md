#Файл посвящен анализу данных коллайдера.
В нем мы будем строить модель, которая будет предсказывать, является ли событие сигналом (частицей Хиггса) или фоном (другими процессами). Мы будем использовать алгоритм XGBoost для обучения модели и оценивать ее качество с помощью метрик, таких как ROC AUC, Precision, Recall и F1-score. Также мы построим ROC-кривую для визуализации производительности модели.
